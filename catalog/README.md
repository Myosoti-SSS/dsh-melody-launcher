# DSH shared catalog analyses

This directory stores reviewed repository analysis records submitted by DSH Melody Launcher users.

- One JSON file represents one GitHub repository.
- The launcher reads merged records before running a new repository scan.
- A record is rescanned when GitHub reports that the source repository was updated after the record.
- Signed-in users submit new results through a fork branch and pull request.
- Pull requests are intentionally merged by a maintainer so untrusted results never become active automatically.

Files under `analysis/` are generated by the launcher. They contain repository metadata and detected install targets only. They must not contain credentials, local paths, downloaded source files, or machine-specific settings.

## Record format

```json
{
  "schemaVersion": 1,
  "repository": "owner/repository",
  "defaultBranch": "main",
  "repositoryUpdatedAt": "2026-08-18T00:00:00Z",
  "analyzedAt": "2026-08-18T00:01:00Z",
  "submittedBy": "github-user",
  "analysis": {
    "repository": "owner/repository",
    "defaultBranch": "main",
    "kind": "plugin",
    "componentKinds": ["plugin"],
    "summary": "...",
    "pluginAnalysis": {},
    "skillAnalysis": null,
    "applicationAnalysis": null,
    "warnings": []
  }
}
```
