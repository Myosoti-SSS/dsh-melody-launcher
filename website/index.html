Why

把繁琐的命令行，收进一个窗口

交互方式参考《我的世界》忘却的旋律启动器：启动之前，先在一个地方把配置、密钥、插件启停和加载顺序都安排妥当。

原本要做的事用启动器之后
装 Node.js → 装 npm → npx @deepseek-ai/dsh 下载一个 exe，点「下载安装 DSH」
手改 .credentials.yaml 填 API Key 界面里输入，自动写入并设为 0600 权限
翻 GitHub 找插件、手敲 dsh plugin add 内置搜索 Topic，一键安装
编辑 profile 的 package.json 调加载顺序 拖动列表，直接改官方 Profile
开终端、记命令、盯输出 一个按钮启动，实时日志面板
Features

核心功能

从 API 配置、插件管理到版本与环境，一个窗口全部搞定。

🔑

API 一键配置

不用再手动编辑凭据文件 —— 在界面里填入 DeepSeek API Key，一键写入本机凭据；同时支持 OpenAI / Anthropic 兼容的自定义服务，多套配置自由保存与切换。Key 仅写入当前 DSH_HOME 的本机凭据文件，启动器不回显、不记录、不上传。

🐙

GitHub 账号登录

支持 OAuth Device Flow 与 Fine-grained Token 两种登录方式。登录后配置随账号同步，凭据经 Electron safeStorage 系统级加密存储；同时还能提高 GitHub API 的请求额度，搜插件更顺畅。

🧩

面板式插件与 Skill 管理

Plugin、Skill、应用加载项与 Agent 预设集中在一张面板：启用状态、加载优先级、版本与兼容性一目了然。拖动即可调整加载顺序，变更直接写入 DSH 官方 Profile，下次启动生效。

🧭

内置 DSH 资源市场

不用再翻 GitHub 找插件 —— 启动器内置资源市场，并行检索 dsh-plugin、dsh-skill 与 dsh-app 三个 Topic，搜索、识别类型、一键安装，全程不离开启动器，安装进度分阶段实时可见。

🏪

DSH Market 精选收录

精选收录社区优质插件与 Skill，按真实仓库内容标记类型，来源可靠、质量有保障。混合仓库会明确列出包含的组件，装什么由你说了算。

📦

整合包一键导入 / 导出

把一组插件、Skill 与配置打包成整合包（Modpack）：一键导出分享给朋友，一键导入完整复现环境。多套配置组合随场景自由切换，像《我的世界》整合包一样简单。

🔄

GitHub 项目同步

登录 GitHub 账号后，可在启动器内直接查看项目的最近提交与变更记录，代码动态简单可查，跟进开发进度不用再打开浏览器翻仓库。

🌿

DSH 与 Node 版本隔离管理

DSH 本体与 Node.js 运行时各自独立管理、相互隔离：多版本并存互不干扰，随时切换当前使用的版本，升级、回滚都放心，再也不用担心环境被搞乱。

🤖

内置 DSH Copilot

遇到报错或兼容问题不用慌 —— 内置 DSH Copilot 能分析当前 DSH 运行环境，对话式排查问题、给出修复建议，新手也能自己搞定环境疑难杂症。

FAQ

常见问题

Windows 提示「不受信任的应用」怎么办？

便携版未使用商业代码签名证书，SmartScreen 会拦截未知发布者的程序。确认文件来自官方 Releases 页面后，点击「更多信息 → 仍要运行」即可。

已经手动装过 DSH，启动器会重复安装吗？

不会。启动器会在运行目录、启动配置、PATH、%APPDATA%\npm 和系统 Node.js 目录中检测已有安装，检测到就直接使用。

停用插件后文件还在硬盘上，正常吗？

正常。停用只是把插件移出 Profile 的有序加载列表，本地依赖保留，方便随时重新启用。只有执行「卸载」才会真正移除文件。

能在 macOS 或 Linux 上用吗？

目前只提供 Windows 便携版（x64 / arm64）。源码在其他平台可以运行开发服务器，但 Node.js 便携运行时的自动准备仅实现了 Windows 分支。

提示「GitHub 请求额度暂时用尽」？

插件搜索使用 GitHub 匿名 API，每小时有速率限制。登录 GitHub 账号可提高额度，或等待一段时间后重试。
